# Жизненный цикл и SEO

- Публичные списки читают PostgreSQL и показывают только будущие события со статусом `PUBLISHED`; demo используется лишь при ошибке подключения.
- Через 6 часов после начала события без `endsAt` или сразу после `endsAt` задача `pnpm lifecycle` переводит его в `FINISHED`.
- Явная отмена, перенос или новая дата извлекаются parser v2. Источник с trust score от 0.8 либо два независимых источника могут обновить событие автоматически; остальные изменения уходят на модерацию.
- Страницы `FINISHED` и `CANCELLED` остаются доступны как архив, но исключаются из листингов. Sitemap снижает их приоритет.
- Endpoint для планировщика: `POST /api/internal/lifecycle/run` с `Authorization: Bearer $CRON_SECRET`.
- Event JSON-LD, canonical metadata, Web App Manifest и динамическое OG-изображение генерируются на сервере.

# Развёртывание на Render

Проект описан в корневом `render.yaml`. Blueprint создаёт веб-сервис, PostgreSQL, постоянный диск для изображений и ежечасную cron-задачу.

## 1. GitHub

Создайте приватный репозиторий и отправьте в него ветку `main`. Файлы `.env` и `.env.production` исключены из Git.

## 2. Blueprint

1. В Render выберите **New → Blueprint**.
2. Подключите GitHub и выберите репозиторий проекта.
3. Render обнаружит `render.yaml`.
4. Во время первого создания заполните секреты:
   - `NEXT_PUBLIC_SITE_URL` — полный адрес, например `https://afisha.example.by`;
   - `ADMIN_PASSWORD` — длинный пароль администратора;
   - `OPENAI_API_KEY` — ключ OpenAI;
   - `OPENAI_EVENT_PARSER_MODEL` — настроенная модель парсера.
5. Подтвердите создание ресурсов.

`AUTH_SECRET` и `CRON_SECRET` Render создаёт автоматически. Подключение к PostgreSQL также передаётся автоматически. Перед каждым развёртыванием выполняются миграции Prisma.

## 3. Домен

После успешного запуска откройте веб-сервис **good-day-afisha → Settings → Custom Domains**, добавьте домен и скопируйте предложенные Render DNS-записи в панель регистратора. HTTPS выпускается автоматически.

После подключения домена проверьте:

- `https://ВАШ-ДОМЕН/api/health`;
- главную страницу;
- `/admin/login`;
- ручной запуск на `/admin/automation`;
- историю первого планового запуска сборщика.

## 4. Перенос текущих данных

Blueprint создаёт пустую базу и постоянный диск. Текущую локальную PostgreSQL и каталог `public/media/events` нужно отдельно перенести в Render перед открытием сайта пользователям. Изображения намеренно не отправляются в GitHub.

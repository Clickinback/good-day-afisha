# Запуск административной панели

1. Скопировать `.env.example` в `.env`.
2. Указать PostgreSQL `DATABASE_URL`.
3. Сгенерировать длинные случайные значения `ADMIN_PASSWORD` и `AUTH_SECRET` (не менее 32 символов для secret).
4. Выполнить `pnpm db:migrate -- --name init`, затем `pnpm db:seed`.
5. Запустить приложение и открыть `/admin/login`.

Текущая environment-password авторизация предназначена для закрытого MVP. Перед доступом нескольких сотрудников её следует заменить на identity provider с отдельными пользователями, ролями `ADMIN/EDITOR/MODERATOR`, MFA и отзывом сессий. `AdminUser` уже добавлен в схему как будущая точка перехода.

Все изменения Event выполняются в транзакции вместе с записью `ModerationLog`. Пароль и секрет не сохраняются в базе и не попадают в клиентский JavaScript.

Форма входа допускает не более пяти неверных попыток с одного IP за 15 минут, после чего блокирует новые попытки на 15 минут. IP хранится только в виде HMAC-хеша на основе `AUTH_SECRET`; успешный вход очищает счётчик.

Каждый успешный вход создаёт уникальную подписанную сессию на 8 часов. Срок действия проверяется и браузером, и сервером; ротация `ADMIN_PASSWORD` или `AUTH_SECRET` отзывает все ранее созданные сессии.

## Добавление источника без JSON

1. Открыть «Источники → Добавить источник», вставить полную ссылку.
2. Указать понятное название (необязательно для автоматического шаблона) и город.
3. Нажать «Проверить источник». Показываются до трёх **исходных материалов**, а не результат ИИ-разбора. Проверка не вызывает OpenAI, не пишет в БД и не сохраняет изображения.
4. Если материалы подходят, отметить «Включить автоматический сбор» и сохранить. Сбор выполнит ближайший плановый цикл; проверка подключения не заменяет модерацию событий.

Готовые шаблоны: публичные Telegram-каналы (`t.me/channel`, `t.me/s/channel`, ссылка на пост нормализуется до канала); Ticketpro — страницы `/koncertnye-ploshhadki/<площадка>/`; HUBL — `https://hubl.by/novopolock/afisha`. Поддержка других разделов этих сайтов не предполагается автоматически.

Неизвестную ссылку можно сохранить выключенной и передать разработчику. Произвольные сайты, RSS и API не объявляются поддерживаемыми. Тип, метод, доверие и JSON скрыты в «Расширенных настройках». Параметры существующего источника сохраняются; применение готового шаблона при редактировании — отдельное явное действие.

Для включения нового/выключенного источника или изменения параметров активного нужна успешная проверка. Её подписанный результат действует 30 минут и привязан к URL, типу, методу и JSON. Изменение только названия, города или доверия у уже активного источника повторной проверки не требует. Кнопка включения в списке ведёт в форму проверки. Выключение доступно сразу.

Preview проверяет авторизацию, DNS/локальные адреса, robots.txt на каждом целевом пути и перенаправлении, ограничивает время (35 секунд), размер (2 МБ на ответ), число запросов (14) и примеры (3). `respectRobots: false` в ручных настройках не отключает эту защиту preview.
